# Elite Showroom

I need to build a premium, highly modern, and sleek automotive dealership web application to replace this outdated site: https://moencoethiopia.com. Please analyze the core content of that URL (Toyota, Suzuki, BYD, Parts, and Service) but completely reimagine the UI/UX.

Please build a responsive, single-page application (SPA) with the following specific requirements:

Aesthetic & Vibe: It needs to feel like a high-end, global automotive showroom (think Tesla or modern Toyota global sites). Use a sophisticated color palette: crisp whites, sleek metallic silvers, deep charcoal/blacks, and bold 'Toyota Red' for the primary Call-To-Action buttons.

Navigation (Crucial Fix): Replace the currently cluttered menu with a clean, sticky navigation bar. Use a modern 'Mega Menu' or dropdowns categorized neatly into: 'Vehicles' (Passenger, SUV, Commercial), 'Machinery', 'Parts & Service', and 'About'.

Hero Section: Create a massive, cinematic hero section at the top. It should feature a high-quality placeholder image of a flagship vehicle (like the Land Cruiser 300) with a bold headline, a glassmorphism search bar to 'Find Your Vehicle', and two clear CTAs: 'Explore Showroom' and 'Book a Service'.

Interactive Vehicle Grid: Fix the current site's boring lists. Create a visually striking 'Featured Vehicles' section. Use sleek product cards with soft hover shadows. Each card should show the car image, name, and a 'View Details' button, removing all redundant text.

Service & Parts Section: Design a dedicated, trust-building section for 'Genuine Parts & Service' with modern iconography. Make the 'Book a Service' action feel like a premium, frictionless experience.

UI Polish: Ensure generous whitespace, rounded corners on cards, and smooth fade-in animations as the user scrolls down the page. Remove any broken video embeds and replace them with a clean 'Latest News' grid.
